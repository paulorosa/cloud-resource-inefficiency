# ADR-0014: GitHub Actions for CI/CD

## Status
Accepted

## Context

Projeto precisa de automação:
- **Testes**: Rodarem em múltiplas versões de Python
- **Lint**: Verificar code style (flake8)\n- **Type Check**: Verificar type hints (mypy --strict)\n- **Coverage**: Medir cobertura de testes\n- **Release**: Automaticamente publicar para PyPI quando tag é criado\n\nSem CI/CD:\n- Testes rodados manualmente (esquecimento, inconsistência)\n- Code review sem automated checks\n- Bugs chegam em produção\n- Releases manuais (propenso a erros)\n\nCom CI/CD:\n- Toda PR testada automaticamente\n- Gatekeeping: PR só pode mergear se testes passem\n- Releases automáticas e confiáveis\n\n## Decision\n\nImplementar **GitHub Actions** com 3 workflows:\n\n### 1. Tests Workflow (`.github/workflows/tests.yml`)\n```yaml\nname: Tests\n\non:\n  push:\n    branches: [main, develop]\n  pull_request:\n    branches: [main, develop]\n\njobs:\n  test:\n    runs-on: ubuntu-latest\n    strategy:\n      matrix:\n        python-version: [\"3.9\", \"3.10\", \"3.11\", \"3.12\"]\n        include-azure: [false, true]\n    \n    steps:\n      - uses: actions/checkout@v3\n      \n      - name: Set up Python\n        uses: actions/setup-python@v4\n        with:\n          python-version: ${{ matrix.python-version }}\n      \n      - name: Install dependencies (base)\n        run: |\n          python -m pip install --upgrade pip\n          pip install -e .[dev]\n      \n      - name: Install Azure (if matrix includes it)\n        if: matrix.include-azure == true\n        run: pip install \".[azure]\"\n      \n      - name: Run flake8 lint\n        run: |\n          flake8 src/ tests/ --max-line-length=100 --extend-ignore=E203,W503\n      \n      - name: Run mypy type check (--strict)\n        run: |\n          mypy --strict src/\n      \n      - name: Run pytest with coverage\n        run: |\n          pytest -v --cov=src/cloud_resource_inefficiency --cov-report=xml tests/\n      \n      - name: Upload coverage to Codecov\n        uses: codecov/codecov-action@v3\n        with:\n          file: ./coverage.xml\n          flags: unittests\n          name: codecov-umbrella\n```\n\n### 2. CI Workflow (`.github/workflows/ci.yml`)\n```yaml\nname: CI\n\non:\n  push:\n    branches: [main]\n  pull_request:\n    branches: [main, develop]\n\njobs:\n  quality-gate:\n    runs-on: ubuntu-latest\n    name: Quality Gate\n    \n    steps:\n      - uses: actions/checkout@v3\n      \n      - name: Set up Python\n        uses: actions/setup-python@v4\n        with:\n          python-version: \"3.11\"\n      \n      - name: Install dependencies\n        run: |\n          pip install -e .[dev,azure]\n      \n      - name: Lint with flake8\n        run: |\n          # Fail on any lint issue\n          flake8 src/ tests/ --count --select=E9,F63,F7,F82 --show-source --statistics\n          flake8 src/ tests/ --count --exit-zero --max-complexity=10 --max-line-length=100\n      \n      - name: Type check with mypy\n        run: mypy --strict src/\n      \n      - name: Test with pytest\n        run: pytest -v --tb=short tests/\n      \n      - name: Build package\n        run: pip install build && python -m build\n```\n\n### 3. Release Workflow (`.github/workflows/release.yml`)\n```yaml\nname: Release to PyPI\n\non:\n  push:\n    tags:\n      - 'v*.*.*'  # Semver tags like v0.2.0\n\njobs:\n  release:\n    runs-on: ubuntu-latest\n    environment: release  # Requer approval em GitHub\n    permissions:\n      contents: read\n      id-token: write  # OIDC token para PyPI\n    \n    steps:\n      - uses: actions/checkout@v3\n      \n      - name: Set up Python\n        uses: actions/setup-python@v4\n        with:\n          python-version: \"3.11\"\n      \n      - name: Install dependencies\n        run: |\n          python -m pip install --upgrade pip\n          pip install build\n      \n      - name: Extract version from tag\n        id: tag_version\n        run: echo \"VERSION=${GITHUB_REF#refs/tags/v}\" >> $GITHUB_OUTPUT\n      \n      - name: Verify version from setuptools-scm\n        run: |\n          pip install -e .\n          python -c \"import cloud_resource_inefficiency; \\\n                     assert cloud_resource_inefficiency.__version__ == '${{ steps.tag_version.outputs.VERSION }}', \\\n                     f'Version mismatch: {cloud_resource_inefficiency.__version__} != ${{ steps.tag_version.outputs.VERSION }}'\"\n      \n      - name: Build package\n        run: python -m build\n      \n      - name: Publish to PyPI\n        uses: pypa/gh-action-pypi-publish@release/v1\n      \n      - name: Create GitHub Release\n        uses: actions/create-release@v1\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n        with:\n          tag_name: ${{ github.ref }}\n          release_name: Release ${{ steps.tag_version.outputs.VERSION }}\n          body: |\n            See [CHANGELOG.md](https://github.com/${{ github.repository }}/blob/main/CHANGELOG.md#${{ steps.tag_version.outputs.VERSION }}) for details.\n          draft: false\n          prerelease: false\n```\n\n## Rationale\n\n1. **Matrix Testing**: Testa Python 3.9-3.12 automaticamente\n2. **Separate Concerns**: Tests, CI quality gate, release são workflows distintos\n3. **Azure Optional**: Testa com/sem Azure (respeita ADR-0012)\n4. **Coverage Tracking**: Codecov integração para histórico de cobertura\n5. **PyPI Publishing**: Automático quando tag é criado\n6. **OIDC**: Token PyPI via OIDC (mais seguro que API key)\n\n## Consequences\n\n### Positive\n- ✅ Testes rodadas automaticamente em toda PR\n- ✅ Lint + type check garantem code quality\n- ✅ Coverage histórico rastreável (Codecov)\n- ✅ Releases automáticas, sem intervenção manual\n- ✅ Múltiplas versões Python testadas em paralelo\n- ✅ Security: Sem API key hardcoded (OIDC)\n\n### Negative\n- ❌ CI/CD pode ser lento (3-5 minutos por run)\n- ❌ Debugging falhas de CI é tedioso (sem acesso local)\n- ❌ Matrix explosion: 4 versões Python × 2 (com/sem Azure) = 8 jobs\n- ❌ GitHub Actions pode ter outages (vendor lock-in)\n\n## Alternatives Considered\n\n### 1. GitLab CI/CD\n```yaml\n# .gitlab-ci.yml\ntest:\n  image: python:3.11\n  script:\n    - pip install -e .[dev]\n    - pytest -v\n```\n**Rejeitado**: Projeto está no GitHub, não GitLab. GitLab CI é similar.\n\n### 2. Jenkins (On-Premise)\n```groovy\nnode {\n    stage('Checkout') { ... }\n    stage('Test') { ... }\n    stage('Release') { ... }\n}\n```\n**Rejeitado**: Requer servidor. Over-engineered para projeto pequeno.\n\n### 3. TravisCI / CircleCI (Cloud Third-Party)\n**Rejeitado**: GitHub Actions é nativo, integrado, gratuito. Por que terceirizá-lo?\n\n## Related Decisions\n\n- **ADR-0010**: Type hints verificados por mypy no CI\n- **ADR-0013**: Semantic versioning com tags Git dispara release\n- **ADR-0012**: CI testa com/sem Azure\n\n## Implementation References\n\n### Key Files\n- `.github/workflows/tests.yml` - Matrix testing, coverage\n- `.github/workflows/ci.yml` - Quality gate\n- `.github/workflows/release.yml` - PyPI publish\n- `.github/dependabot.yml` - Automático dependency updates (optional)\n\n### Branch Protection Rules\nConfigurar em GitHub repo settings:\n```\nBranch: main\n✓ Require status checks to pass:\n  - test (all matrix combinations)\n  - ci (quality gate)\n✓ Require code reviews: 1\n✓ Dismiss stale PR approvals\n✓ Require branches up to date before merging\n```\n\n### Codecov Integration\n```yaml\n- uses: codecov/codecov-action@v3\n  with:\n    files: ./coverage.xml\n    flags: unittests\n    name: codecov-umbrella\n    fail_ci_if_error: false  # Don't block if codecov is down\n```\n\n### Release Process (Complete)\n```bash\n# 1. Atualizar CHANGELOG.md com release notes\n# 2. Commit e push\ngit add CHANGELOG.md\ngit commit -m \"chore: Prepare v0.2.0 release\"\ngit push origin main\n\n# 3. Criar tag (setuptools-scm detecta)\ngit tag v0.2.0 -m \"Release version 0.2.0\"\n\n# 4. Push tag (dispara workflow release.yml)\ngit push origin v0.2.0\n\n# 5. GitHub Actions:\n#    - Detecta tag\n#    - Roda tests\n#    - Constrói package\n#    - Publica para PyPI\n#    - Cria GitHub Release\n\n# 6. Usuários podem instalar\npip install cloud-resource-inefficiency==0.2.0\n```\n\n### Debugging CI Failures\n\n**Tester Localmente**:\n```bash\n# Simular GitHub Actions localmente com Act\npip install act\nact -l  # List workflows\nact push  # Simula push trigger\nact pull_request  # Simula PR trigger\n\n# Ou simular manual\npip install -e .[dev,azure]\npytest -v\nmypy --strict src/\nflake8 src/ tests/\n```\n\n## Notes\n\n- **GitHub Actions Limits**: 20 concurrent jobs. Se matrix fica muito grande, considerar split\n- **Secrets Management**: Não commitear secrets. Usar GitHub Secrets\n- **Cache**: Possível adicionar caching de dependencies para speed up\n  ```yaml\n  - uses: actions/cache@v3\n    with:\n      path: ~/.cache/pip\n      key: ${{ runner.os }}-pip-${{ hashFiles('**/requirements.txt') }}\n  ```\n- **Artifact Retention**: Default é 90 dias. Customizável\n- **Self-Hosted Runners**: Se performance é crítica, considerar self-hosted runners\n"
