# ADR-0011: Thread-Safe Client Factories with Lazy Initialization

## Status
Accepted

## Context

Clientes cloud (boto3, Google Cloud SDK, Azure SDK) são **custosos de criar**:
- Inicializar boto3 client: ~50-100ms (credentials, config setup)
- Múltiplas regiões: 10 regiões × 50ms = 500ms extra
- Múltiplos provedores: AWS + GCP + Azure = 1000ms+

Padrões:
1. **Eager Initialization**: Criar todos os clientes na startup
2. **Lazy Initialization**: Criar clientes sob demanda
3. **Connection Pooling**: Reaproveitar conexões

Sem cache/reaproveitement:
```python\n# ❌ Ruim: Cada chamada cria novo cliente\ndef get_metrics(resource, region):\n    client = boto3.client('cloudwatch', region_name=region)  # NOVO CLIENTE CADA VEZ!\n    return client.get_metric_statistics(...)\n\n# 100 chamadas × 100ms = 10 segundos desnecessários\n```\n\nCom lazy + cache:\n```python\n# ✅ Bom: Cliente é criado uma vez e reutilizado\nclass AWSClientFactory:\n    def get_client(self, service, region):\n        key = f\"{service}:{region}\"\n        if key not in self._cache:\n            self._cache[key] = boto3.client(service, region_name=region)\n        return self._cache[key]\n\n# 1ª chamada: criar cliente (100ms)\n# 2-100ª chamadas: reusar cliente (<1ms)\n```\n\nEntretanto, **thread-safety é crítico**:\n```python\n# ❌ Race condition: Dois threads criando cliente simultaneamente\nif key not in self._cache:  # Thread A passa aqui\n    # Thread B passa aqui também\n    self._cache[key] = boto3.client(...)  # Ambos criam, um sobrescreve\n    # Possível memory leak ou state inconsistency\n```\n\n## Decision\n\nImplementar **Lazy Initialization com threading.Lock**:\n\n### Para AWS\n```python\n# providers/aws/client_factory.py\nimport threading\nfrom typing import Any, Dict, Optional\nimport boto3\nfrom botocore.config import Config\n\nclass AWSClientFactory:\n    \"\"\"Factory para criar e cachear clientes boto3 thread-safe\"\"\"\n    \n    def __init__(\n        self,\n        session: Optional[boto3.Session] = None,\n        profile_name: Optional[str] = None,\n        aws_access_key_id: Optional[str] = None,\n        aws_secret_access_key: Optional[str] = None,\n        aws_session_token: Optional[str] = None,\n        botocore_config: Optional[Config] = None,\n    ) -> None:\n        \"\"\"Inicializa factory com credenciais opcionais\"\"\"\n        if session is not None:\n            self._session = session\n        elif profile_name:\n            self._session = boto3.Session(profile_name=profile_name)\n        elif aws_access_key_id and aws_secret_access_key:\n            self._session = boto3.Session(\n                aws_access_key_id=aws_access_key_id,\n                aws_secret_access_key=aws_secret_access_key,\n                aws_session_token=aws_session_token,\n            )\n        else:\n            self._session = boto3.Session()  # Usa credenciais do ambiente\n        \n        self._config = botocore_config or Config(retries={\"max_attempts\": 3, \"mode\": \"standard\"})\n        self._client_cache: Dict[str, Any] = {}\n        self._lock = threading.Lock()\n    \n    @property\n    def session(self) -> boto3.Session:\n        return self._session\n    \n    def get_client(self, service_name: str, region_name: Optional[str] = None) -> Any:\n        \"\"\"Retorna cliente cacheid ou cria novo (thread-safe)\"\"\"\n        cache_key = f\"{service_name}:{region_name or 'default'}\"\n        \n        # Double-checked locking pattern para performance\n        if cache_key in self._client_cache:\n            return self._client_cache[cache_key]\n        \n        # Lock para evitar race condition\n        with self._lock:\n            # Check again depois de adquirir lock\n            if cache_key in self._client_cache:\n                return self._client_cache[cache_key]\n            \n            # Criar novo cliente\n            kwargs: Dict[str, Any] = {\"config\": self._config}\n            if region_name:\n                kwargs[\"region_name\"] = region_name\n            \n            client = self._session.client(service_name, **kwargs)\n            self._client_cache[cache_key] = client\n        \n        return self._client_cache[cache_key]\n    \n    def __repr__(self) -> str:\n        return (\n            f\"<AWSClientFactory session={id(self._session)} \"\n            f\"cached_clients={len(self._client_cache)}>\"\n        )\n```\n\n### Para GCP\n```python\n# providers/gcp/client_factory.py\nfrom google.cloud import storage, logging as cloud_logging, monitoring\nfrom google.auth.transport.requests import Request\nfrom google.oauth2.service_account import Credentials\n\nclass GCPClientFactory:\n    \"\"\"Factory para GCP clients com caching thread-safe\"\"\"\n    \n    def __init__(\n        self,\n        project_id: Optional[str] = None,\n        credentials_path: Optional[str] = None,\n    ) -> None:\n        self._project_id = project_id\n        self._credentials_path = credentials_path\n        self._clients: Dict[str, Any] = {}\n        self._lock = threading.Lock()\n    \n    def get_storage_client(self) -> storage.Client:\n        with self._lock:\n            if \"storage\" not in self._clients:\n                self._clients[\"storage\"] = storage.Client(\n                    project=self._project_id\n                )\n            return self._clients[\"storage\"]\n    \n    def get_logging_client(self) -> cloud_logging.Client:\n        with self._lock:\n            if \"logging\" not in self._clients:\n                self._clients[\"logging\"] = cloud_logging.Client(\n                    project=self._project_id\n                )\n            return self._clients[\"logging\"]\n    \n    def get_monitoring_client(self) -> monitoring.MetricServiceClient:\n        with self._lock:\n            if \"monitoring\" not in self._clients:\n                self._clients[\"monitoring\"] = monitoring.MetricServiceClient()\n            return self._clients[\"monitoring\"]\n```\n\n### Para Azure\n```python\n# providers/azure/client_factory.py\nfrom azure.identity import DefaultAzureCredential\nfrom azure.mgmt.compute import ComputeManagementClient\nfrom azure.mgmt.monitor import MonitorManagementClient\n\nclass AzureClientFactory:\n    \"\"\"Factory para Azure clients com caching thread-safe\"\"\"\n    \n    def __init__(self, subscription_id: str) -> None:\n        self._subscription_id = subscription_id\n        self._credential = DefaultAzureCredential()\n        self._clients: Dict[str, Any] = {}\n        self._lock = threading.Lock()\n    \n    def get_compute_client(self) -> ComputeManagementClient:\n        with self._lock:\n            if \"compute\" not in self._clients:\n                self._clients[\"compute\"] = ComputeManagementClient(\n                    credential=self._credential,\n                    subscription_id=self._subscription_id,\n                )\n            return self._clients[\"compute\"]\n    \n    def get_monitor_client(self) -> MonitorManagementClient:\n        with self._lock:\n            if \"monitor\" not in self._clients:\n                self._clients[\"monitor\"] = MonitorManagementClient(\n                    credential=self._credential,\n                    subscription_id=self._subscription_id,\n                )\n            return self._clients[\"monitor\"]\n```\n\n## Rationale\n\n1. **Performance**: Lazy initialization evita overhead desnecessário\n2. **Thread-Safety**: Lock garante consistência em ambientes multi-threaded\n3. **Memory Efficiency**: Cache apenas clientes necessários\n4. **Double-Checked Locking**: Otimização para evitar lock desnecessário após primeira criação\n5. **Flexibility**: Múltiplas estratégias de autenticação por factory\n\n## Consequences\n\n### Positive\n- ✅ Clientes criados apenas quando necessário\n- ✅ Reaproveitement de conexões reduz latência\n- ✅ Thread-safe: múltiplos threads podem usar mesma factory\n- ✅ Memory overhead mínimo (clientes em cache enquanto vivos)\n- ✅ Fácil mockar para testes\n\n### Negative\n- ❌ Synchronization overhead (lock acquisition)\n- ❌ Lock contention se muitos threads acessarem simultaneamente\n- ❌ State compartilhado (cache) pode ser confuso\n- ❌ Clientes não são automaticamente encerados (resource leak se não limpar)\n\n## Alternatives Considered\n\n### 1. Eager Initialization (Todos os Clientes na Startup)\n```python\nclass AWSClientFactory:\n    def __init__(self, regions):\n        self._clients = {}\n        for region in regions:\n            for service in [\"ec2\", \"cloudwatch\", \"pricing\"]:\n                key = f\"{service}:{region}\"\n                self._clients[key] = boto3.client(service, region_name=region)\n```\n**Rejeitado**: Startup lento. Se incluir 10 regiões × 3 serviços = 30 clientes, 3 segundos na startup.\n\n### 2. Thread-Local Storage (Sem Compartilhamento)\n```python\nimport threading\n\nclass AWSClientFactory:\n    def __init__(self):\n        self._thread_local = threading.local()\n    \n    def get_client(self, service, region):\n        if not hasattr(self._thread_local, \"cache\"):\n            self._thread_local.cache = {}\n        # Cada thread tem seu próprio cache\n        # Sem contention, mas cada thread cria clientes\n```\n**Rejeitado Parcialmente**: Menos memory efficient (N threads × clientes). Sem compartilhamento de conexões.\n\n### 3. Connection Pooling com `queue.Queue`\n```python\nfrom queue import Queue\n\nclass AWSClientFactory:\n    def __init__(self, pool_size=5):\n        self._pool = Queue(maxsize=pool_size)\n        for _ in range(pool_size):\n            self._pool.put(boto3.client(...))\n```\n**Rejeitado**: Over-engineered. Pool management é complexo. Não necessário para este projeto.\n\n## Related Decisions\n\n- **ADR-0001**: Client factories implementam strategy para cada provedor\n- **ADR-0005**: Cache de pricing/metrics complementa client factory\n\n## Implementation References\n\n### Key Files\n- `src/cloud_resource_inefficiency/providers/aws/client_factory.py`\n  - `AWSClientFactory` com boto3 caching\n- `src/cloud_resource_inefficiency/providers/gcp/client_factory.py`\n  - `GCPClientFactory` com Google Cloud SDK caching\n- `src/cloud_resource_inefficiency/providers/azure/client_factory.py`\n  - `AzureClientFactory` com Azure SDK caching\n\n### Usage in Collectors\n```python\nclass AWSEBSCollector(BaseResourceCollector):\n    def __init__(self, client_factory: AWSClientFactory):\n        self._client_factory = client_factory\n    \n    def collect(self, region: str, **kwargs) -> List[CloudResource]:\n        # Reutiliza cliente do factory\n        ec2_client = self._client_factory.get_client(\"ec2\", region)\n        response = ec2_client.describe_volumes()\n        # ... processar response\n```\n\n## Notes\n\n- **Cleanup**: Clientes não são automaticamente \"desligados\". Se necessário, adicionar método `close_all()` que itera sobre cache e fecha cada cliente\n- **Region Override**: AWS permite `client.meta.region_name` para descobrir região do cliente\n- **Retry Config**: Passed ao Config (botocore) para configurar retry behavior por cliente\n- **Distributed Scenarios**: Se houver múltiplos processos (não threads), cada processo tem seu próprio factory/cache\n"
