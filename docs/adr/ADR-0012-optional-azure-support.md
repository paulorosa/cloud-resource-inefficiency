# ADR-0012: Optional Azure Support via Extras

## Status
Accepted

## Context

Azure é um provedor cloud importante, mas nem todos os usuários precisam:
- Alguns times usam **só AWS**\n- Outros usam **AWS + GCP**\n- Alguns usam **AWS + Azure**
- Poucos usam **todos os três**\n\nAzure dependencies são grandes:\n- `azure-identity`: Autenticação (~2 MB)\n- `azure-mgmt-compute`: Compute resources (~5 MB)\n- `azure-mgmt-monitor`: Monitoring (~3 MB)\n- **Total: ~10 MB extra** para usuários que não usam Azure\n\nProblema sem optional support:\n```bash\n# Instalação obrigatória de Azure packages\npip install cloud-resource-inefficiency\n# Instala: boto3 + google-cloud-* + azure-* = ~50 MB (bloat)\n# Mesmo se usuário só usa AWS\n```\n\nCom optional support:\n```bash\n# Base: Só AWS e GCP\npip install cloud-resource-inefficiency\n# ~30 MB\n\n# Com Azure (opt-in)\npip install \"cloud-resource-inefficiency[azure]\"\n# ~40 MB (agora com Azure)\n```\n\n## Decision\n\nImplementar Azure como **optional dependency** via setuptools \"extras\":\n\n### pyproject.toml\n```toml\n[project]\nname = \"cloud-resource-inefficiency\"\ndynamic = [\"version\"]\ndescription = \"...\"\nrequires-python = \">=3.9\"\n\n# Dependências obrigatórias (AWS + GCP)\ndependencies = [\n    \"boto3>=1.26.0\",\n    \"google-cloud-storage>=2.0\",\n    \"google-cloud-logging>=3.0\",\n    \"google-cloud-monitoring>=2.0\",\n]\n\n[project.optional-dependencies]\n# Azure é opcional\nazure = [\n    \"azure-identity>=1.12.0\",\n    \"azure-mgmt-compute>=30.0.0\",\n    \"azure-mgmt-monitor>=6.0.0\",\n]\n\n# Dev dependencies (testes, lint, type check)\ndev = [\n    \"pytest>=7.0.0\",\n    \"pytest-cov>=4.0.0\",\n    \"mypy>=1.0.0\",\n    \"flake8>=6.0.0\",\n    \"pyyaml>=6.0\",\n]\n```\n\n### Instalação\n```bash\n# Opção 1: Base (AWS + GCP)\npip install cloud-resource-inefficiency\n\n# Opção 2: Com Azure\npip install \"cloud-resource-inefficiency[azure]\"\n\n# Opção 3: Com dev tools\npip install \"cloud-resource-inefficiency[dev]\"\n\n# Opção 4: Tudo\npip install \"cloud-resource-inefficiency[azure,dev]\"\n```\n\n### Código: Importação Condicional\n```python\n# providers/__init__.py\nfrom cloud_resource_inefficiency.providers.aws import register_aws_provider\nfrom cloud_resource_inefficiency.providers.gcp import register_gcp_provider\n\n# Azure é opcional\ntry:\n    from cloud_resource_inefficiency.providers.azure import register_azure_provider\n    HAS_AZURE = True\nexcept ImportError:\n    HAS_AZURE = False\n    register_azure_provider = None  # type: ignore\n\ndef register_providers(\n    registry: InefficiencyRegistry,\n    include_azure: bool = False,\n) -> None:\n    \"\"\"Registra provedores disponíveis\"\"\"\n    register_aws_provider(registry)\n    register_gcp_provider(registry)\n    \n    if include_azure:\n        if not HAS_AZURE:\n            raise ImportError(\n                \"Azure support not installed. \"\n                \"Install with: pip install cloud-resource-inefficiency[azure]\"\n            )\n        register_azure_provider(registry)\n```\n\n### Scanner: Auto-Detection com Fallback Gracioso\n```python\n# engine/scanner.py\nclass InefficiencyScanner:\n    def __init__(\n        self,\n        registry: Optional[InefficiencyRegistry] = None,\n        providers: Optional[List[CloudProvider]] = None,\n        regions: Optional[List[str]] = None,\n        auto_register_defaults: bool = True,\n    ) -> None:\n        self.registry = registry or default_registry\n        self.providers = providers or [CloudProvider.AWS]\n        self.default_regions = regions or [\"us-east-1\"]\n        \n        if auto_register_defaults:\n            # AWS: Sempre disponível\n            if CloudProvider.AWS in self.providers:\n                if not self.registry.get_rules_for_provider(CloudProvider.AWS):\n                    register_aws_provider(registry=self.registry)\n            \n            # GCP: Sempre disponível\n            if CloudProvider.GCP in self.providers:\n                if not self.registry.get_rules_for_provider(CloudProvider.GCP):\n                    register_gcp_provider(registry=self.registry)\n            \n            # Azure: Condicional\n            if CloudProvider.AZURE in self.providers:\n                if not HAS_AZURE:\n                    raise RuntimeError(\n                        \"Azure support not installed. \"\n                        \"Install with: pip install cloud-resource-inefficiency[azure]\"\n                    )\n                if not self.registry.get_rules_for_provider(CloudProvider.AZURE):\n                    register_azure_provider(registry=self.registry)\n```\n\n### Testes: Condicional também\n```python\n# tests/test_azure_support.py\nimport pytest\nfrom cloud_resource_inefficiency.providers import HAS_AZURE\n\n@pytest.mark.skipif(not HAS_AZURE, reason=\"Azure support not installed\")\ndef test_azure_managed_disk_collection():\n    # Testes Azure rodam apenas se Azure instalado\n    pass\n```\n\n## Rationale\n\n1. **Tamanho Menor**: Usuários base economizam 10 MB\n2. **Rápido Setup**: Instalação mais rápida (menos packages)\n3. **Flexibilidade**: Instalar Azure conforme necessário\n4. **Standard**: Pattern padrão em Python (extras em setuptools)\n5. **Graceful Degradation**: App funciona sem Azure, erro claro se usar Azure sem instalar\n\n## Consequences\n\n### Positive\n- ✅ Instalação base mais leve (AWS + GCP)\n- ✅ Usuários Azure instalam explicitamente (opt-in)\n- ✅ Reduz dependencies desnecessárias\n- ✅ CI/CD pode testar com/sem Azure\n- ✅ Documentação clara sobre instalação\n\n### Negative\n- ❌ Importação condicional é menos limpa (try/except)\n- ❌ Erros em runtime se Azure não instalado (não em import time)\n- ❌ Testes de Azure requerem skip condicional\n- ❌ Setup mais complexo para desenvolvimento (instalar todas as extras)\n- ❌ Auto-discovery de provedores fica mais complexa\n\n## Alternatives Considered\n\n### 1. Dependência Obrigatória\n```toml\ndependencies = [\n    \"boto3>=1.26.0\",\n    \"google-cloud-*\",\n    \"azure-*\",  # OBRIGATÓRIO\n]\n```\n**Rejeitado**: 10 MB extra para usuários que não usam Azure. Package bloat.\n\n### 2. Separar em Pacotes Distintos\n```bash\npip install cloud-resource-inefficiency-aws  # Base\npip install cloud-resource-inefficiency-azure  # Separate package\n```\n**Rejeitado**: Múltiplos packages complexifica manutenção, versioning, coordenação.\n\n### 3. Lazy Import de Azure\n```python\n# Importar Azure apenas quando necessário\nif CloudProvider.AZURE in providers:\n    # Lazy import\n    from cloud_resource_inefficiency.providers.azure import ...\n```\n**Adotado Parcialmente**: Feito com try/except e HAS_AZURE flag.\n\n## Related Decisions\n\n- **ADR-0001**: Multi-Provider Architecture habilita optional providers\n- **ADR-0014**: CI/CD testa com/sem extras\n\n## Implementation References\n\n### Key Files\n- `pyproject.toml` - Definição de extras\n- `src/cloud_resource_inefficiency/providers/__init__.py`\n  - `HAS_AZURE` flag\n  - `register_providers()` com include_azure\n- `src/cloud_resource_inefficiency/engine/scanner.py`\n  - Auto-registration condicional\n  - Erro claro se Azure não instalado\n- `tests/conftest.py`\n  - Skip condicional para testes Azure\n\n### Users: Installation Guide\n\n**Instalação Padrão (AWS + GCP)**:\n```bash\npip install cloud-resource-inefficiency\n```\n\n**Com Azure**:\n```bash\npip install \"cloud-resource-inefficiency[azure]\"\n```\n\n**Desenvolvimento (todas as extras + dev tools)**:\n```bash\npip install -e \".[azure,dev]\"\n```\n\n**requirements.txt**:\n```txt\n# Opção 1: Base\ncloud-resource-inefficiency>=0.2.0\n\n# Opção 2: Com Azure\ncloud-resource-inefficiency[azure]>=0.2.0\n\n# Opção 3: Via git\ngit+https://github.com/paulorosa/cloud-resource-inefficiency.git#egg=cloud-resource-inefficiency[azure]\n```\n\n### GitHub Actions CI/CD\n\n```yaml\n# .github/workflows/tests.yml\njobs:\n  test:\n    runs-on: ubuntu-latest\n    strategy:\n      matrix:\n        python-version: [\"3.9\", \"3.10\", \"3.11\", \"3.12\"]\n        include-azure: [false, true]\n    \n    steps:\n      - uses: actions/checkout@v3\n      - uses: actions/setup-python@v4\n        with:\n          python-version: ${{ matrix.python-version }}\n      \n      - name: Install dependencies (base)\n        run: pip install -e .[dev]\n      \n      - name: Install Azure (if needed)\n        if: matrix.include-azure == true\n        run: pip install \".[azure]\"\n      \n      - name: Run tests\n        run: pytest -v\n```\n\n## Notes\n\n- **Import Guard**: Usar `HAS_AZURE` flag para evitar ImportError em runtime\n- **Documentation**: Adicionar seção em README.md sobre instalação com extras\n- **Version Pinning**: Manter versões de extras em sync com versões testadas\n- **Future**: Se mais provedores forem adicionados (Alibaba Cloud, Kubernetes, etc.), seguir mesmo padrão\n"
